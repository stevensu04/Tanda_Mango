## Made in code (no external files)

All other sound is synthesised in the browser by `web/src/club-audio.ts` and `web/src/pix/sfx.ts`: the club beat (kick, clap, hat, bass), the three-note hook (D4 F4 E4), Gus's closed-mouth hum, the street layer (murmur, footsteps, cloth, stanchion clinks), the rope clasp, the door, the reveal sting and the chip cues. These are original to this project and carry the project's licence.

## Not used yet

The brief prefers real recordings (door handle, metal rope clasp, shoe soles, low crowd) and a relaxed human hum for Gus. None is in the build yet; the synthesised versions stand in. Any recording added later goes in the table above with its source and licence (e.g. a CC0 or CC BY clip, with the author named if the licence asks for it).
